# Дневник головной боли

Приложение-дневник для iPhone (PWA), которое ставится на экран «Домой» и работает без сервера.
**Все записи хранятся только в телефоне** — никуда не отправляются.

Открыть: **https://edwardnurgalin.github.io/migraine-diary/**

Дизайн и сценарий заполнения — по мотивам N1-Headache: бирюзовый — день без боли,
розовый — головная боль, фиолетовый — приступ, похожий на мигрень.

## Установка на iPhone

1. Откройте ссылку выше **в Safari**.
2. «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».
3. Дальше открывайте **только иконку «Дневник»**. У Safari и у иконки на iPhone разные хранилища:
   записи, сделанные во вкладке Safari, в иконке не появятся.
4. В «Настройках» дневника добавьте свои лекарства и город (для давления и температуры).

После первого открытия дневник работает и без интернета. Интернет нужен только для погоды.

## Что умеет

- **Дневник** — полоса последних дней и вопрос «Болела ли голова?». Дальше пошаговое заполнение:
  приступ (время, сила 1–10, где и какая боль) → симптомы → лекарства с эффектом → разделы факторов
  (эмоции, сон, питание, образ жизни, окружение, поездки, женское здоровье) → заметка.
  Разделы включаются и выключаются в настройках; справочник — [`docs/config.js`](docs/config.js).
- **«Похоже на мигрень»** — приступ размечается автоматически по признакам ICHD-3
  (критерии C и D или аура). Это подсказка для врача, не диагноз.
- **Календарь** — месяц с цветными кружками, отметки лекарств и менструации.
- **Мои данные** — за 30/90/180 дней: график боли и давления, лекарства и их эффективность,
  проверка злоупотребления обезболивающими (ICHD-3: 10 дней в месяц для триптанов и
  комбинированных, 15 — для простых), **карта провокаторов** и **карта защиты** (после 30 заполненных дней).
- **Отчёт для врача** — страница за любой период, «Печать / PDF» сохраняет её в PDF.
- **Погода** — давление, температура, влажность из Open-Meteo по выбранному городу (бесплатно, без ключей).

## Резервная копия — обязательно

Данные живут только в телефоне. Если удалить иконку или очистить данные Safari, записи пропадут.
Раз в неделю дневник сам напомнит: «Настройки» → «Сохранить копию в „Файлы“» → выберите iCloud Drive.
Восстановить: «Настройки» → «Восстановить из копии» → выбрать файл `дневник-копия-….json`.
Копией же можно перенести дневник на новый телефон.

## Напоминание каждый вечер

Без сервера дневник не может сам присылать уведомления. Проще всего встроенными «Напоминаниями»:
новое напоминание «Заполнить дневник» → дата и время 21:00 → «Повтор: ежедневно».

## Разбор с Claude

«Настройки» → «Разбор с Claude» → «Отправить в Claude…» (или «Скопировать текст» и вставить в чат).
Дневник готовит текст за последние 30 дней с просьбой разобрать частоту приступов, провокаторы,
эффективность лекарств и вопросы к неврологу.

## Данные из «Здоровья» (по желанию)

Веб-приложение не может само читать «Здоровье», поэтому данные передаются через буфер обмена.
Один раз соберите команду в приложении «Команды»:

1. «+» → «Добавить действие» → **«Найти образцы здоровья»**: тип «Вариабельность сердечного ритма»,
   дата начала «за последние 1 дн.», сортировка «Дата начала», «Сначала новые», ограничение 1.
2. Ещё одно **«Найти образцы здоровья»**: «Пульс в покое», те же условия.
3. Ещё одно **«Найти образцы здоровья»**: «Шаги», дата начала «сегодня»; затем **«Вычислить статистику»** → «Сумма».
4. **«Текст»**, в три строки (значения вставляются как переменные из шагов 1–3):
   ```
   hrv: [образцы шага 1]
   resting_hr: [образцы шага 2]
   steps: [статистика шага 3]
   ```
5. **«Скопировать в буфер обмена»**. Назовите команду «Дневник: Здоровье».

Утром запустите команду (можно с виджета), откройте дневник → «Настройки» → «Вставить данные из „Здоровья“».
Можно добавить строку `sleep: 7.5` — сон в часах (или минутах). Сон также вводится прямо в разделе «Сон».
Эта команда не проверялась на настоящем iPhone — если что-то не сработает, данные можно вставить в поле вручную.

## Для разработки

```
docs/          сайт (GitHub Pages публикует эту папку)
  index.html   оболочка
  app.js       интерфейс
  api.js       работа с данными: дни, лекарства, настройки, копии, CSV, текст для Claude
  stats.js     статистика, мигрень по ICHD-3, злоупотребление лекарствами, провокаторы
  store.js     IndexedDB
  weather.js   погода и поиск города (Open-Meteo)
  config.js    разделы и факторы
  sw.js        офлайн-кэш; меняйте VERSION при каждом обновлении
tests/         проверки расчётов
tools/make_icons.py  генерация иконок
```

Запуск локально:

```bash
python3 -m http.server 8766 --directory docs
```

Проверки:

```bash
node --test tests/*.test.mjs
```

Первый коммит в истории — прежняя версия с сервером (FastAPI + SQLite).
