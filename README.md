# Дневник головной боли

Веб-приложение (PWA), которое ставится на телефон как обычное: запись приступов в пару нажатий,
календарь, статистика, учёт лекарств и злоупотребления обезболивающими, погода и давление,
отчёт для врача (печать / PDF) и выгрузка в CSV.

Дизайн и сценарий заполнения — по мотивам N1-Headache: тёмная тема, бирюзовый — день без боли,
розовый — головная боль, фиолетовый — приступ, похожий на мигрень.

## Что умеет сейчас

- **Дневник** — полоса последних дней и вопрос «Болела ли голова?». Дальше пошаговое заполнение:
  приступ (время, сила 1–10, где и какая боль) → симптомы → лекарства с эффектом → разделы факторов
  (эмоции, сон, питание, образ жизни, окружение, поездки, женское здоровье) → заметка.
  Факторы с уровнями (нет / немного / заметно / сильно), счётчиками (чашки кофе) и переключателями.
  Разделы включаются и выключаются в настройках; справочник — `app/config.py`.
- **«Похоже на мигрень»** — приступ размечается автоматически по признакам ICHD-3 (критерии C и D или аура).
  Это подсказка для врача, не диагноз.
- **Календарь** — месяц с цветными кружками, отметки лекарств и менструации.
- **Мои данные** — за 30/90/180 дней: график боли и давления, сводка, лекарства и их эффективность,
  проверка злоупотребления обезболивающими (пороги ICHD-3: 10 дней для триптанов и комбинированных,
  15 — для простых), **карта провокаторов** и **карта защиты** (после 30 заполненных дней).
- **Отчёт для врача** — печатная страница за любой период, сохраняется в PDF через «Печать».
- **Погода** — Open-Meteo по выбранному городу, без ключей и оплаты.
- **Данные из «Здоровья»** — `POST /api/health` принимает сон, пульс покоя, ВСР и шаги
  (будет вызываться из команды iPhone на следующем этапе).

## Запуск локально

```bash
uv venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/uvicorn app.main:app --port 8765
```

Откройте http://localhost:8765. База — `data/diary.db` (путь меняется переменной `DIARY_DB`).

## Ключ доступа

Если задать `DIARY_TOKEN`, каждый запрос к API должен присылать его в заголовке `X-Token`;
приложение спросит ключ при первом входе и запомнит его на устройстве.
**На сервере в интернете ключ обязателен** — это медицинские данные.

```bash
DIARY_TOKEN=длинный-случайный-ключ .venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8765
```

## Структура

```
app/main.py      API и раздача приложения
app/db.py        схема SQLite
app/stats.py     статистика, злоупотребление лекарствами, факторы
app/weather.py   погода и поиск города (Open-Meteo)
app/static/      PWA: index.html, app.js, style.css, sw.js, manifest, иконки
tools/make_icons.py  генерация иконок
```
